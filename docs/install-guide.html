Installation Steps

1
Install Docker
Run the official Docker convenience script. Works on Ubuntu, Debian, RHEL, and CentOS.
bash — run as root or with sudo
# Install Docker Engine
curl -fsSL https://get.docker.com | sh
sudo systemctl enable --now docker

# Optional: run docker without sudo (log out and back in after)
sudo usermod -aG docker $USER
ℹ

Already have Docker? Skip this step. docker --version confirms it's installed.

2
Install Docker Compose
Docker Compose may already be included with Docker. Check first.
bash — check which version is available
# Check if already installed (either version works)
docker compose version    # V2 (preferred)
docker-compose --version  # V1 (also supported)
bash — install V2 plugin if neither is available
# Ubuntu / Debian
sudo apt-get update && sudo apt-get install -y docker-compose-plugin

# RHEL / CentOS
sudo yum install -y docker-compose-plugin
3
Install Git
Needed to clone the repo and receive future updates via git pull.
bash
# Ubuntu / Debian
sudo apt-get install -y git curl

# RHEL / CentOS
sudo yum install -y git curl
4
Clone the Repository
Clone into a directory that will persist across reboots. /opt or /data are good choices.
bash
git clone https://github.com/albinbenny-dev/qa-infinity.git
cd qa-infinity
chmod +x start.sh
5
Configure Environment
Run start.sh once — it creates .env from the template and exits with instructions.
bash
./start.sh
# Exits and asks you to fill in .env

nano .env
# Or: vi .env
Variable Description Example
POSTGRES_PASSWORD PostgreSQL password. Set once — cannot change after DB initializes without ALTER ROLE. MyStr0ng!Pass REQUIRED
JWT_SECRET Signing secret for auth tokens. Any long random string. 3 concatenated UUIDs REQUIRED
ANTHROPIC_API_KEY Anthropic API key (if using LLM_PROVIDER=anthropic). sk-ant-api03-... REQUIRED*
OPENROUTER_API_KEY OpenRouter key (alternative to Anthropic). sk-or-v1-... REQUIRED*
CORS_ORIGIN URL the browser uses to reach the UI. Set to the server's IP if accessing remotely. http://10.0.6.3:3100 recommended
ALLOWED_DOMAINS Restrict registration to these email domains. Leave blank for any domain. 6dtech.co.in optional
JIRA_HOST / JIRA_API_TOKEN Jira integration for the Writer Agent. Leave blank to skip. optional

* One LLM provider key is required. Set LLM_PROVIDER=anthropic or LLM_PROVIDER=openrouter to match the key you provide.

6
Start QA Infinity
Run start.sh again. It detects first run, builds all Docker images (~3–5 min), starts the stack, and health-checks the API.
bash
./start.sh
⚠

First build takes 3–5 minutes. Docker compiles the API and bundles the frontend. Subsequent starts are instant — images are cached.

7
Verify & Register
Once start.sh reports the stack is ready, open these URLs from a browser.
UI
http://<server-ip>:3100
Main application
API Health
http://<server-ip>:4100/health
Should return {"status":"ok"}
Live Runner View
http://<server-ip>:6180
noVNC — watch tests execute in real time
✓

First account gets Super Admin. Go to /register and create your account — it's automatically granted the Super Admin role.

Updating to the Latest Version

🔄 Routine update — code changes only (API / UI)
git pull && ./start.sh --build
📦 Full rebuild — after dependency or Dockerfile changes
git pull && ./start.sh --build
# start.sh detects image changes and does a full rebuild automatically

Other Commands

View live logs
./start.sh --logs

Troubleshooting

  • UI loads but API calls fail — check CORS_ORIGIN in .env matches the URL in your browser exactly (including port).
  • Stack starts but login fails immediately — JWT_SECRET is likely empty; set it and run ./start.sh --build.
  • API container exits on start — run sudo docker logs qa-api to read the error. Usually a missing .env variable.
  • Port already in use — another process is on 3100 or 4100. Find it with sudo ss -tlnp | grep 3100 and stop it.
  • Build fails with "no space left" — free disk space with sudo docker system prune -f (safe — only removes unused images/containers).
  • "unknown shorthand flag: 'd'" — your Docker is V1 (docker-compose). start.sh handles this automatically; make sure you cloned the latest version.
