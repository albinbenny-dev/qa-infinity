Windows users — Docker Desktop requires WSL 2. When you install Docker Desktop it will guide you through enabling it. You'll also need Git Bash (installed with Git for Windows) to run the start.sh script in Step 5.

Installation Steps
1
Install Docker Desktop
Download and install Docker Desktop for your OS. Start it after install — the whale icon in the system tray means it's running.
📥

Download from docker.com/products/docker-desktop and run the installer. Enable WSL 2 when prompted.

PowerShell — verify after install
# Check Docker is running
docker --version
docker compose version
📥

Download from docker.com/products/docker-desktop. Choose the right chip — Apple Silicon (M1/M2/M3) or Intel.

Terminal — verify after install
docker --version
docker compose version
bash — Ubuntu/Debian
curl -fsSL https://get.docker.com | sh
sudo systemctl enable --now docker
# Run docker without sudo (re-login after)
sudo usermod -aG docker $USER
2
Install Git
Git is needed to clone the repo. Windows users: the Git for Windows installer also installs Git Bash, which you need in Step 5.
📥

Download from git-scm.com/download/win. During install, accept the defaults — this installs Git Bash automatically.

Terminal
# Usually pre-installed. If not:
xcode-select --install
bash
# Ubuntu / Debian
sudo apt-get install -y git
# RHEL / CentOS
sudo yum install -y git
3
Clone the Repository
Clone into any folder. On Windows, open Git Bash (right-click on Desktop → "Git Bash Here") and run these commands.
Git Bash / Terminal / bash
git clone https://github.com/albinbenny-dev/qa-infinity.git
cd qa-infinity
chmod +x start.sh   # Linux/Mac/Git Bash only
🔒

Private repo — you need to be added as a collaborator on GitHub first. Ask the team lead to grant access.

4
Create and Configure .env
Copy the template and fill in the required values. Open the file in any text editor — Notepad, VS Code, nano, whatever you prefer.
PowerShell — in the qa-infinity folder
Copy-Item .env.example .env
code .env   # opens in VS Code — or use notepad .env
Terminal
cp .env.example .env
code .env   # VS Code, or: nano .env
VariableWhat to set
POSTGRES_PASSWORD Any strong password. Pick once — can't easily change it later without resetting the DB volume. REQUIRED
JWT_SECRET A long random string. Paste 2–3 UUIDs together from uuidgenerator.net. REQUIRED
LLM_PROVIDER Set to anthropic (default) or openrouter. REQUIRED
ANTHROPIC_API_KEY Your Anthropic API key if using LLM_PROVIDER=anthropic. REQUIRED*
OPENROUTER_API_KEY Your OpenRouter key if using LLM_PROVIDER=openrouter. REQUIRED*
CORS_ORIGIN Leave as http://localhost:3100 for local access. keep default
ALLOWED_DOMAINS Email domain restriction for registration (e.g. 6dtech.co.in). Leave blank to allow any email. optional
APP_MODE Keep full for a dev laptop (includes AI agents). Set runner only for air-gapped client deployments. keep default
5
Start QA Infinity
This builds all Docker images on the first run (~3–5 min). Subsequent starts are fast — images are cached.
⚠

Use Git Bash, not PowerShell or CMD — start.sh is a bash script. Right-click the qa-infinity folder and choose "Git Bash Here".

Git Bash — inside the qa-infinity folder
./start.sh
Terminal — inside the qa-infinity folder
./start.sh
⏳

First build takes 3–5 minutes. Docker is compiling the API, building the frontend, and pulling base images. You'll see build output scroll by. Once you see "All services are healthy", you're ready.

6
Open the App & Register
Once the stack is running, open your browser. The first account you register gets the Super Admin role automatically.
Main App
http://localhost:3100
UI — login / register here
API Health
http://localhost:4100/health
Should return {"status":"ok"}
Live Runner
http://localhost:6180
noVNC — watch tests run in real time
✓

Go to http://localhost:3100/register to create your account. The first account is automatically Super Admin. Subsequent accounts need an invite or can self-register if ALLOWED_DOMAINS matches their email.

Troubleshooting
  • Docker Desktop not starting on Windows Make sure WSL 2 is enabled: open PowerShell as Administrator and run wsl --install, then restart.
  • Port 3100 or 4100 already in use Another app is using the port. Find it on Windows: netstat -ano | findstr :3100. Kill it, or edit the port mapping in docker-compose.yml (e.g. change 3100:80 to 3200:80) and update CORS_ORIGIN in .env to match.
  • UI loads but API calls fail (CORS error) Check that CORS_ORIGIN in .env matches the URL in your browser exactly, including the port.
  • Login fails immediately after registering JWT_SECRET is likely empty or too short. Set it to a long random string and restart: ./start.sh --build.
  • API container keeps restarting Run docker logs qa-api to see the error. Usually a missing required variable in .env.
  • "permission denied" running ./start.sh on Mac/Linux Run chmod +x start.sh first.
  • Build fails with "no space left on device" Docker has run out of disk space. Free it with docker system prune -f (safe — only removes unused images and stopped containers).
  • Registration page says "domain not allowed" Your email domain is blocked by ALLOWED_DOMAINS. Either use an email with the allowed domain, or clear ALLOWED_DOMAINS in .env and restart.
